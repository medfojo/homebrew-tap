# homebrew-tap

Homebrew tap for [tagboard](https://github.com/medfojo/tagboard) — a cloud-backed terminal note-taking app.

## Install

```bash
brew install medfojo/tap/tagboard-tui
```

This automatically adds the tap on first use. To add the tap without installing:

```bash
brew tap medfojo/tap
```

## Upgrade

```bash
brew upgrade tagboard-tui
```

## Uninstall

```bash
brew uninstall tagboard-tui
```

## Supported platforms

- macOS (Apple Silicon, arm64)
- macOS (Intel, x86_64)
